# codedrill
Mία εφαρμογή εκμάθησης κώδικα με την οποία κάποιος χρήστης μπορεί να πληκτρολογεί τις εντολές που του ζητούνται αφού έχει επιλέξει εξ αρχής με ποια γλώσσα προγραμματισμού θέλει να εξασκηθεί.
## Σύνοψη Προδιαγραφών Εφαρμογής
Stack & Αρχιτεκτονική: React / Vite, TypeScript, Tailwind CSS (Front-End SPA).

Αποθήκευση Δεδομένων: localStorage για αυτόματη διατήρηση μεταξύ συνεδριών + Λειτουργίες Export/Import αρχείων .json.

Editor & Σύγκριση: Custom <textarea> με monospace γραμματοσειρά, πλήρη υποστήριξη Tab indentation και αυστηρή σύγκριση χαρακτήρα-προς-χαρακτήρα (Exact Match).

Διαχείριση Εντολών & Γλωσσών (CRUD): Πλήρης πίνακας διαχείρισης με προειδοποιητικό modal επιβεβαίωσης κατά τη διαγραφή γλώσσας (Cascade Delete).

Modes Εξάσκησης (Υβριδικό):

Free Play / Continuous (Ανακύκλωση εντολών)

Time Attack (Αντίστροφη μέτρηση)

Fixed Target (Στόχος επαναλήψεων)

Practice Features: Randomization/Shuffle, ηχητικά εφέ (με διακόπτη On/Off), οπτική επιβεβαίωση (Πράσινο/Κόκκινο), κουμπί «Εμφάνιση Λύσης / Hint», στατιστικά επιτυχίας.

Initial State: Empty State (με καθοδηγητικά prompts για εισαγωγή δεδομένων ή δημιουργία της πρώτης γλώσσας/εντολής).

UI/UX: Sidebar Layout (αριστερή πλευρική μπάρα πλοήγησης και στατιστικών).
